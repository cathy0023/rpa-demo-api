# 企业微信后台配置清单（给企业管理员）

应用：销售侧边栏助手（自建应用）
域名：**wecom.nonoai.com.cn** → 服务器 47.89.150.106
请按顺序在「企业微信管理后台」（work.weixin.qq.com，管理员账号登录）完成以下配置。

---

## 1. 配置应用可信域名

路径：**应用管理 → 自建应用 → 销售侧边栏助手（代理ID 1000004）→ 开发者接口 → 网页授权及JS-SDK → 可信域名**

1. 填入 `wecom.nonoai.com.cn`（不带 https:// 前缀）。
2. 企微会要求**下载域名校验文件 `WW_verify_XXXX.txt`**。
3. 把该文件发给技术人员，放到前端目录 `dist/` 下并上传服务器（见 deploy/README.md「WW_verify 域名校验文件放置说明」）。
4. 技术人员确认 `https://wecom.nonoai.com.cn/WW_verify_XXXX.txt` 能在浏览器直接打开后，回后台点「验证」，验证通过后保存可信域名。

> 常见失败原因：文件还没上传就点验证；文件名或内容被改动；nginx 未部署完成。遇到失败请先让技术人员确认第 4 步的 URL 可访问。

## 2. 配置聊天工具栏（侧边栏）页面地址

路径：**应用管理 → 自建应用 → 销售侧边栏助手 → 工作台应用信息 / 聊天工具栏配置**

- 页面地址填：`https://wecom.nonoai.com.cn/sidebar.html`
- 该地址将在聊天工具栏（会话侧边栏）中打开，必须为上面配置的可信域名下的 HTTPS 页面。

## 3. 添加企业可信 IP

路径：**应用管理 → 自建应用 → 销售侧边栏助手 → 开发者接口 → 企业可信IP**

需要把以下两个 IP 都加入（缺一个 API 调用就会报 60020 not allow to access from your ip）：

| IP | 用途 |
|---|---|
| `47.89.150.106` | 生产服务器（阿里云 ECS）出口，调用企微 API 的来源 |
| `222.131.66.30` | 当前办公/开发网络出口（本地联调调用企微 API 时使用） |

> 后续办公网络出口 IP 变化时需同步更新此列表。

## 4. 设置应用可见范围

路径：**应用管理 → 自建应用 → 销售侧边栏助手 → 可见范围**

- 勾选**销售部门**（及需要使用侧边栏的其他部门/人员）。
- 可见范围外的成员不会在聊天工具栏看到该应用。

## 5. 重启企业微信客户端生效

配置保存后，**提醒所有使用人员完全退出并重新登录企业微信客户端**（手机端和桌面端都要），新的可信域名与聊天工具栏配置才会生效。仅保存配置不重启，侧边栏可能仍显示空白或旧配置。

## 6. 会话存档说明（当前未开通）

- 本应用当前**未开通会话存档**功能，服务端已按降级模式运行（`WECOM_SID_ENABLED=false`）。
- 影响：涉及会话存档的高级能力（拉取聊天记录等）不可用；侧边栏的基础功能（页面打开、OAuth 登录、常规 API）不受影响。
- 如后续需要开通：需在企业微信管理后台申请「会话存档」权限（可能涉及付费与合规审批），开通后由技术人员将服务端 `WECOM_SID_ENABLED` 改为 `true` 并重启服务。
